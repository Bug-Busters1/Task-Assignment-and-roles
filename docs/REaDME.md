# نظام مساعد الجودة والفرز الذكي للباقات (QA Assistant System & Smart AI-Powered Bug Triage)

## نظرة عامة (Overview)
يُعد هذا المشروع منصة ذكية متكاملة لإدارة اختبارات البرمجيات، تتبع العيوب، ورفع كفاءة الفرز باستخدام تقنيات الذكاء الاصطناعي ومعالجة اللغات الطبيعية (NLP). يهدف النظام إلى مساعدة فرق اختبار البرمجيات (QA) في تحسين عمليات الإبلاغ عن الأخطاء وتصنيفها واكتشاف التكرار تلقائياً، مع إبقاء قرار المراجعة والاعتماد النهائي بيد العنصر البشري (Human-in-the-Loop).

## الغرض من المشروع (Project Purpose)
- أتمتة وتطوير دورة حياة اكتشاف وإدارة الباجات (Bug Life Cycle).
- تقليل الوقت الضائع في الفرز اليدوي للأخطاء (Manual Triage).
- توفير مؤشرات أداء دقيقة وقابلة للقياس لجودة النظام وأداء نموذج الذكاء الاصطناعي.
