# تقييم ومواجهة المخاطر (Risk Assessment and Mitigation Plan)
[⬅️ العودة إلى الصفحة الرئيسية](../README.md)

## نظرة عامة على تقييم المخاطر
لضمان تسليم المشروع في موعده المحدد وبأعلى جودة، تم رصد المخاطر المحتملة وتحديد استراتيجيات التعامل معها مسبقاً:

| المخاطر المحتملة (Risk) | مستوى التأثير (Impact) | استراتيجية التخفيف والحل (Mitigation Strategy) |
| :--- | :--- | :--- |
| **انخفاض دقة نموذج الذكاء الاصطناعي في تصنيف الباجات** | عالي | تنظيف وتجهيز مجموعة بيانات تدريبية موثوقة (Dataset Preprocessing) وتطبيق تقنيات تحسين النماذج (Fine-tuning). |
| **تأخر في التكامل بين الـ Backend ومحرك الـ AI** | متوسط | توحيد عقود واجهات البرمجة (API Contracts) والاعتماد على توثيق Swagger/Postman منذ البداية. |
| **مشاكل في إدارة الوقت وتداخل مهام الفريق** | متوسط | استخدام منهجية Agile/Scrum وتحديد مخرجات (Deliverables) واضحة لكل مرحلة زمنية. |
