# مؤشرات الأداء الرئيسية (KPIs & System Metrics)
[⬅️ العودة إلى الصفحة الرئيسية](../README.md)

تم وضع معايير صارمة وقابلة للقياس لتقييم جودة السيستم وكفاءة نموذج الذكاء الاصطناعي:

## أ) KPIs الخاصة بجودة السيستم (System Quality)
| مؤشر الأداء (KPI) | المعادلة الحسابية | الهدف المستهدف (Target) |
| :--- | :--- | :--- |
| **Test Case Pass Rate** | (Passed ÷ Total) × 100 | $\ge 90\%$ |
| **Defect Density** | Total Bugs ÷ Total Modules | $< 5$ |
| **Defect Removal Efficiency** | (Bugs Found Before Release ÷ Total) × 100 | $\ge 95\%$ |
| **Test Coverage** | (Tested Features ÷ Total) × 100 | $100\%$ |
| **MTTD (Mean Time to Detect)** | Sum of Detection Times ÷ Total Bugs | $< 2$ يوم |
| **MTTR (Mean Time to Resolve)** | Sum of Resolution Times ÷ Total Bugs | $< 5$ أيام |

## ب) KPIs الخاصة بأداء الذكاء الاصطناعي (AI Performance)
| مؤشر الأداء (KPI) | المعادلة الحسابية | الهدف المستهدف (Target) |
| :--- | :--- | :--- |
| **Classification Accuracy** | (Correct AI Suggestions ÷ Total) × 100 | $\ge 80\%$ |
| **Duplicate Detection Precision** | (True Duplicates ÷ Total Flagged as Duplicate) × 100 | $\ge 75\%$ |
| **Recommendation Acceptance Rate** | (Accepted AI Suggestions ÷ Total) × 100 | $\ge 70\%$ |
| **Time Saved in Triage** | Manual Triage Time - Automated Triage Time | $\ge 50\%$ توفير بالوقت |
