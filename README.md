# Project Documentation Hub

Welcome to the official documentation repository for our automated software testing and AI bug-triage project. This repository serves as the central hub for our architectural designs, team responsibilities, and project workflows.

## Overview

This project integrates advanced Natural Language Processing (NLP) models with a robust backend and an intuitive frontend dashboard to automate software bug categorization, priority prediction, duplicate detection, and comprehensive quality assurance testing.
